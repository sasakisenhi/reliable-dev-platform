## Reliable Development Convergence Additions

### Upstream Integrity

Before converting a discrepancy into additional implementation work, distinguish a genuine
code gap from invalid or stale upstream intent.

If the discrepancy originates from an incorrect requirement, material assumption, feature
boundary, or significant plan decision, do not manufacture downstream implementation tasks
solely to satisfy that artifact.

Identify the canonical upstream owner that requires revision and require affected downstream
artifacts to be revalidated before convergence continues.
